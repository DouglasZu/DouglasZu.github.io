## Do not publish without evidence

- “1,500+ automated tests”
- “247 tests in 42.3 seconds” or “96.4% pass rate”
- “70% regression reduction”
- “150+ endpoints with 98% reliability”
- “40% API response-time improvement”
- Certifications without issuer and credential URL
- Articles without a published URL
- Project cards that do not link directly to a repository or live artifact

## Evidence expected for a strong project claim

- Repository URL and descriptive topics
- One-command setup and test execution
- Screenshot, trace, report or short demo
- Architecture or test-pyramid diagram
- Test strategy and scope boundaries
- CI workflow with downloadable artifacts
